# Andina Cargo

Technical test for Crazy Imagine Software.

Shipment tracking system that receives events from multiple carriers,
normalizes them into a common domain model and exposes a query API
and web dashboard.

## Stack

- Node.js 22+
- TypeScript
- NestJS
- Next.js
- PostgreSQL / Supabase

## Project structure

- `apps/api` - NestJS API
- `apps/web` - Next.js dashboard
- `packages/shared` - Shared TypeScript contracts
